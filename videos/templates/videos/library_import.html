Download videos with yt-dlp

Install yt-dlp, then run this command in Terminal. Replace /absolute/path/to/your/media-folder with the same path above and YOUTUBE_URL with a video or playlist link. Wait for the download to finish before scanning.

python3 -m pip install -U yt-dlp

yt-dlp \
  --yes-playlist \
  --write-info-json \
  --write-thumbnail \
  --write-comments \
  --clean-info-json \
  -o "%(uploader)s/%(title)s [%(id)s].%(ext)s" \
  -P "/absolute/path/to/your/media-folder" \
  "YOUTUBE_URL"

The metadata and thumbnail files are saved beside each video. On every scan, YourTube removes unused yt-dlp fields, converts dates and comment timestamps, and then refreshes the database.
