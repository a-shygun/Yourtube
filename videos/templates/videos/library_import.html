Download with yt-dlp

  1. 1. Create a links file

    Create video-urls.txt and put one YouTube video, playlist, or channel URL on each line. The download and metadata files will be saved in the media folder selected below.

  2. 2. Install yt-dlp and open its config

    Run these commands in Terminal on your Mac. The config file is ~/.config/yt-dlp/config.

    brew install yt-dlp
mkdir -p ~/.config/yt-dlp
nano ~/.config/yt-dlp/config

    Paste this configuration into the editor, then save and exit.

    # Use Safari cookies or change to chrome
--cookies-from-browser safari
-f "bv[ext=mp4][height<=720]+ba[ext=m4a][language^=en]/b[ext=mp4][height<=720][language^=en]/bv[ext=webm][height<=720]+ba[ext=webm][language^=en]/b[ext=webm][height<=720][language^=en]"
--ignore-errors
--write-info-json
--write-comments
--extractor-args "youtube:max_comments=50"
--playlist-end 50
--write-thumbnail
--no-write-subs
--no-write-auto-subs
--no-embed-subs
-o "/absolute/path/to/your/media/%(title)s - %(channel)s/%(title)s.%(ext)s"
  3. 3. Download the URLs

    For a manual download, run this loop from the YourTube project folder. Set the config output path to your chosen media folder.

    for url in $(grep -vE '^[[:space:]]*(#|$)' video-urls.txt); do
  yt-dlp "$url"
done
  4. 4. Add the folders to YourTube

    Set yt-dlp’s output path to the same folder you enter in YourTube. Then click Scan folder and import below.

Choose your media folder

Enter the absolute path to an existing local folder as seen by the computer running YourTube. It can be outside the YourTube project, including an external drive. Choose the folder containing your video folders, not the drive root or a broad parent folder. YourTube needs read and write access because it normalizes yt-dlp metadata during import. The folder path is saved for later imports and video playback.
