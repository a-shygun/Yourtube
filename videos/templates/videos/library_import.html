YOUR LOCAL LIBRARY

Bring in your YouTube files

YourTube stores video files on the computer running this site. The hosted site cannot fetch files onto your device, so run YourTube locally when you want to download videos. Metadata and downloaded files stay in your local media/ folder.

Download with yt-dlp

  1. 1. Create a links file

    Create video-urls.txt and put one YouTube video, playlist, or channel URL on each line. Save it in the YourTube project folder, beside the media/ directory.

  2. 2. Install yt-dlp and open its config

    Run these commands in Terminal on your Mac. The config file is ~/.config/yt-dlp/config.

    brew install yt-dlp
mkdir -p ~/.config/yt-dlp
nano ~/.config/yt-dlp/config

    Paste this configuration into the editor, then save and exit.

    # Use Safari cookies or change to chrome
--cookies-from-browser safari
-f "bv[ext=mp4][height<=720]+ba[ext=m4a][language^=en]/b[ext=mp4][height<=720][language^=en]/bv[ext=webm][height<=720]+ba[ext=webm][language^=en]/b[ext=webm][height<=720][language^=en]"
--ignore-errors
--write-info-json
--write-comments
--extractor-args "youtube:max_comments=50"
--playlist-end 50
--write-thumbnail
--no-write-subs
--no-write-auto-subs
--no-embed-subs
-o "media/%(title)s - %(channel)s/%(title)s.%(ext)s"
  3. 3. Download the URLs

    From the YourTube project folder, run this loop. Each URL is passed to yt-dlp, and the config saves its files under media/.

    for url in $(grep -vE '^[[:space:]]*(#|$)' video-urls.txt); do
  yt-dlp "$url"
done
  4. 4. Add the folders to YourTube

    Make sure the downloaded video folders are in this project’s media/ directory, then click Scan media/ and import below.

Import files you already have

Place the raw yt-dlp folders in this project’s media/ directory. Import cleans the metadata JSON, removes incomplete temporary files and duplicate video formats, rebuilds the model JSON files in helper/data/, then adds or updates videos in the database and removes videos no longer represented in media/. Existing accounts, profile data, and watch toggles for videos that remain are preserved.

{% csrf_token %}

Downloads can be large. The importer skips files without valid video info JSON, and rerunning it updates matching video URLs instead of duplicating them. YouTube access and download behavior depend on your local network and yt-dlp version.
